## 3.0.50~3.0.67（versionCode 30067）— 2026-08-30

> 3.0.50~3.0.67 系列（桌面卡片 + CI 自动打包/发布 + 版本号同步机制）

### ✨ 新功能
- **桌面卡片「快速记录」**：桌面长按应用图标 → 服务卡片 → 添加「快速记录」卡片（2×2 ArkTS 卡片）；点击卡片直接拉起应用，自动切到「此刻」页并弹出新建记录弹窗
- **GitHub Actions 自动打包**：push master 自动构建 unsigned HAP（容器镜像 HarmonyOS Command Line Tools 6.0.2.650）；产物命名 `RecordLife_V<versionName>.hap`（版本号自动读取）
- **自动发布 GitHub Release**：推送 `v*` tag 时自动构建并发布 Release（名 `RecordLife v<tag>`，资产即上述 HAP）
- **版本号同步机制**：应用版本号（AppScope/app.json5）与 git 提交前缀统一为 3.0.x，每次提交对应唯一可追溯版本

### 🎨 体验优化
- 个性化页排版统一（左右滑动 + 顶部对齐 + 存储口径修复）
- 存储空间页补齐返回按钮（与其他子页一致的 44×44 点击区）
- 桌面卡片样式打磨：渐变背景 + 装饰圆 + 白底加号 + 日期 + 操作提示

### 🐛 修复
- CI 构建 SignHap 报错（signingConfigs 指向本机 Windows 路径证书，Linux runner 不存在）→ 构建前临时移除签名配置
- 桌面卡片四角露白/白边（内容圆角与宿主圆角不匹配）→ 渐变铺满 Stack + 宿主统一裁切圆角

### 🛠 技术演进
- 本地命令行构建链路：`DEVECO_SDK_HOME` + hvigorw.bat 验证编译
- notify skill（Reasonix 任务完成右下角弹窗，Windows）
- CI 流水线：容器镜像 + ohpm install + hvigorw assembleHap + sed 版本提取 + artifact/Release 上传

## 3.0.x（versionCode 30049）— 2026-08-23

> 3.0.1~3.0.49 系列（重构 P0~P8 + 更新计划 + UI/云存储迭代）

### ✨ 新功能
- **主题配色**：我的 → 个性化 8 色主色板，全局配色实时切换（深色模式自动调亮保对比度），重启保留
- **云存储（腾讯云 COS）**：
  - 本地只存压缩图（高清/均衡/省空间三档），原图存云端，可「查看原图 / 保存原图到本地」
  - 「上传全部图片」：历史补传 + 进度条 + 上传前去重（云端被删自动补传）+ 上传后删原图开关
  - 云存储总开关、自定义访问域名、测试连接、可读 key（日期目录）
  - 修改/删除记录自动同步云端（旧图删除、新图上传）
- **图片预览升级**：Swiper 滑动翻页 + 捏合缩放（1~5x）+ 双击放大 + 放大后平移，退出仅按钮/系统返回
- 我的页/更多页 UI 重构：分组卡片 + emoji 彩色圆角图标、隐私模式/清理缓存归位
- 个性化管理（标签/心情/模板）删除**二次确认**

### 🎨 体验优化
- 子页面返回按钮统一 44×44 点击区 + 图标 24；删除撤销条移至顶部
- 图片压缩保留画质（q0.92）→ 三档可调；存储页防重复加载

### 🐛 修复
- 预览手势多次冲突（Swiper 拦截/覆盖/禁用）→ 手势分层最终方案
- 主题配色名称不随选择实时更新（SettingItem 普通参数机制）→ 内联驱动
- 签名/座右铭不参与配置导入导出 → 补齐
- 上传全部后老图显示为空（单例内存未刷新）→ reloadRecords
- 存储空间页图片重复显示（并发加载）→ 防重入

### 🛠 技术演进
- COS V5 签名自实现（HmacSha1 纯 ArkTS，零第三方依赖；content-type/域名签名修正）
- 数据模型全部可选字段扩展（C1~C6 旧备份兼容）

## 2.3.0（versionCode 23000）— 2026-08-23

> 从 2.0.0 起累计改动（中间 2.1.x/2.2.x 为开发版本，未单独发布，直接以 2.3.0 发布）

### ✨ 新功能

#### 记录体验
- **心情标记**：新增/编辑记录可添加心情（😊😌🤩😢😴 5 档预置 + **自定义心情**），记录卡片展示心情 emoji，支持按心情筛选
- **撤销删除**：删除记录后 3 秒内可一键撤销（含图片完整恢复），带倒计时进度条提示
- **记录模板**：预设常用记录模板，新增记录时**一键填充**内容；模板可自定义增删改（并入个性化管理）

#### 首页（"活着"）
- **生命进度环形**：首页顶部实时显示已度过生命进程百分比（与目标年龄对比）
- **签名/座右铭**：可在我的页设置，首页标题区展示
- **字体大小设置**：小/中/大三档，实时作用于记录内容

#### 数据与统计
- **数据看板**（我的页入口）：记录总数 / 活跃天数 / 日均 / 最长连续天数 / 累计字数 / 记录区间
- **生命进度 + 里程碑**：环形进度 + 已活年月日明细 + 11 个生命里程碑（1000 天 / 1 万天 / 2 万天 / 3 万天 / 18 岁 / 30 岁 / 50 岁 / 目标年龄 1/4、1/2、3/4、满程），已达成/倒计时一目了然

#### 效率与隐私
- **缓存清理**：一键清理临时分享图片与无引用图片
- **隐私模式**：开启后隐藏首页出生日期、生命里程碑与我的页生日（🔒 遮罩）
- **引导页**：首次安装展示 4 页功能引导（重置后重新展示）

#### 其他
- **自定义标签/心情/模板**统一在「个性化管理」分页管理
- 全局中英文双语（新增功能全部国际化）

### 🎨 体验优化
- **筛选交互重构**：筛选栏从横向滑动改为「此刻」旁的**筛选按钮 + 弹出气泡**，心情/标签分组选择，带筛选摘要与计数
- **我的页改版**：顶部用户区主题色渐变；设置项分组卡片化（常规/数据/个性化/更多）+ 图标
- **标签管理弹窗**：改 Tab 分页（标签 / 心情 / 模板），不再堆叠
- 首页布局协调（生命进度环形归位标题行）

### 🐛 修复
- 修复多次筛选后记录消失（重新筛选恢复）的问题
- 修复重置应用与首次安装示例数据行为不一致
- 修复字体大小设置保存失败
- 修复编辑/删除记录等场景的编译与运行错误
- 清理资源冲突、废弃 API、异常处理等全部编译警告

### 🛠 技术演进（开发者视角）
- **架构分层重构**：`model / repository / service / viewmodel / components` 清晰分层，ConfigManager 瘦身、IO 职责下沉
- **依赖注入**：单例支持显式 context 注入（A5），消除全局状态依赖
- **可测试性**：新增 69 个单元测试（时间计算 / 统计 / 农历转换 / 配置校验等纯函数）
- **日志统一**：console 全部收敛到 hilog 封装（Logger）

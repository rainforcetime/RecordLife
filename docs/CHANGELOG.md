# RecordLife 更新日志（Changelog）

## 2.3.0（versionCode 23000）— 2026-08-23

> 从 2.0.0 起累计改动（中间 2.1.x/2.2.x 为开发版本，未单独发布，直接以 2.3.0 发布）

### ✨ 新功能

#### 记录体验
- **心情标记**：新增/编辑记录可添加心情（😊😌🤩😢😴 5 档预置 + **自定义心情**），记录卡片展示心情 emoji，支持按心情筛选
- **撤销删除**：删除记录后 3 秒内可一键撤销（含图片完整恢复），带倒计时进度条提示
- **记录模板**：预设常用记录模板，新增记录时**一键填充**内容；模板可自定义增删改（并入个性化管理）

#### 首页（"活着"）
- **生命进度环形**：首页顶部实时显示已度过生命进程百分比（与目标年龄对比）
- **签名/座右铭**：可在我的页设置，首页标题区展示
- **字体大小设置**：小/中/大三档，实时作用于记录内容

#### 数据与统计
- **数据看板**（我的页入口）：记录总数 / 活跃天数 / 日均 / 最长连续天数 / 累计字数 / 记录区间
- **生命进度 + 里程碑**：环形进度 + 已活年月日明细 + 11 个生命里程碑（1000 天 / 1 万天 / 2 万天 / 3 万天 / 18 岁 / 30 岁 / 50 岁 / 目标年龄 1/4、1/2、3/4、满程），已达成/倒计时一目了然

#### 效率与隐私
- **缓存清理**：一键清理临时分享图片与无引用图片
- **隐私模式**：开启后隐藏首页出生日期、生命里程碑与我的页生日（🔒 遮罩）
- **引导页**：首次安装展示 4 页功能引导（重置后重新展示）

#### 其他
- **自定义标签/心情/模板**统一在「个性化管理」分页管理
- 全局中英文双语（新增功能全部国际化）

### 🎨 体验优化
- **筛选交互重构**：筛选栏从横向滑动改为「此刻」旁的**筛选按钮 + 弹出气泡**，心情/标签分组选择，带筛选摘要与计数
- **我的页改版**：顶部用户区主题色渐变；设置项分组卡片化（常规/数据/个性化/更多）+ 图标
- **标签管理弹窗**：改 Tab 分页（标签 / 心情 / 模板），不再堆叠
- 首页布局协调（生命进度环形归位标题行）

### 🐛 修复
- 修复多次筛选后记录消失（重新筛选恢复）的问题
- 修复重置应用与首次安装示例数据行为不一致
- 修复字体大小设置保存失败
- 修复编辑/删除记录等场景的编译与运行错误
- 清理资源冲突、废弃 API、异常处理等全部编译警告

### 🛠 技术演进（开发者视角）
- **架构分层重构**：`model / repository / service / viewmodel / components` 清晰分层，ConfigManager 瘦身、IO 职责下沉
- **依赖注入**：单例支持显式 context 注入（A5），消除全局状态依赖
- **可测试性**：新增 69 个单元测试（时间计算 / 统计 / 农历转换 / 配置校验等纯函数）
- **日志统一**：console 全部收敛到 hilog 封装（Logger）
